# Puripat Rattanapupetch — Web Portfolio

This repository contains the static website prepared for GitHub Pages. Open `index.html` locally or publish the repository with GitHub Pages.

## Privacy review

The public-ready copy omits screenshots that expose residents' names, home addresses, national ID numbers, ages, welfare status, claimant records, uploaded evidence, or live spreadsheet rows. Some project screenshots are replaced with neutral workflow diagrams.

The site includes the owner's profile photo and `resume.pdf`, which contains the owner's contact details for recruitment.
